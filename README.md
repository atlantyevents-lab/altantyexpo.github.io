# Атланты Экспо — тестовый лендинг

Публикация через GitHub Pages в репозитории `atlantyevents-lab/altantyexpo.github.io`.

## Как опубликовать
1. Загрузите содержимое этой папки в корень репозитория (`index.html`, `.nojekyll`).
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Сайт откроется на `https://altantyexpo.github.io/`.

`index.html` — один самодостаточный файл: стили, шрифты, фото и анимации внутри, внешних
зависимостей нет. Правится только исходник `Expo-B-Coal.dc.html`, после чего файл собирается заново.
